# Experiment 5: Establishment of LAN Using a Switch

## Aim
To establish a Local Area Network (LAN) by connecting multiple computers through a network switch using Cisco Packet Tracer, configure IP addresses for each computer, and verify communication between the connected devices.

## Software Used
- Cisco Packet Tracer

## Description
This experiment involves connecting multiple computers to a network switch using straight-through cables. Unique IP addresses and subnet masks are assigned to each computer. Communication between devices is tested using the `ping` command to verify successful LAN connectivity.

## Result
Successfully established a LAN using a network switch, configured IP addresses, and verified communication between connected computers using Cisco Packet Tracer.

# Experiment 7: Peer-to-Peer Network Connection Using Switch and Router

## Aim
To establish a peer-to-peer network connection between two computer systems using a switch and router in a Local Area Network (LAN), configure IP addressing, and verify communication between the systems.

## Software Used
- Cisco Packet Tracer

## Description
This experiment involves connecting two computer systems through a network switch and router using appropriate network cables. IP addresses, subnet masks, and default gateways are configured for both systems. Communication is tested using the `ping` command to verify successful data transmission.

## Result
Successfully established a peer-to-peer network connection between two computer systems using a switch and router and verified communication using Cisco Packet Tracer.

# Experiment 12: Exploring Network Simulation and Monitoring Tools

## Aim
To explore various networking tools such as NS-3, OMNeT++, GNS3, pfSense, and Wireshark, and understand their applications in network simulation, configuration, security, and monitoring.

## Software Used
- NS-3
- OMNeT++
- GNS3
- pfSense
- Wireshark

## Description
This experiment involves exploring different networking tools used for network simulation, emulation, security, and traffic analysis. These tools help understand network behavior, configure virtual networks, monitor data packets, and analyze network performance.

## Result
Successfully explored various networking tools and understood their functions and applications in network simulation, security, and monitoring.

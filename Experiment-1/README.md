# Experiment 1: Study of Network Cables

## Aim
To study different types of network cables and practically implement cross-wired cable and straight-through cable connections using Cisco Packet Tracer.

## Software Used
- Cisco Packet Tracer

## Description
This experiment involves studying different types of network cables, including straight-through, crossover, and rollover cables. Their connections are implemented and tested using Cisco Packet Tracer to understand their applications in networking.

## Result
Successfully studied different types of network cables and implemented straight-through and crossover cable connections using Cisco Packet Tracer.

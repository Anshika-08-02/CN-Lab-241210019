# Experiment 4: IP Addressing and LAN Configuration

## Aim
To study and configure network IP addressing using Cisco Packet Tracer and establish communication between devices in a Local Area Network (LAN).

## Software Used
- Cisco Packet Tracer

## Description
This experiment involves assigning IP addresses and subnet masks to network devices and connecting them through a switch to establish a Local Area Network (LAN). Connectivity between devices is verified using the `ping` command.

## Result
Successfully configured IP addressing and established communication between devices in a Local Area Network using Cisco Packet Tracer.

# Experiment 10: Client-Server Communication Using TCP and UDP

## Aim
To study and simulate client-server applications using TCP and UDP protocols in Cisco Packet Tracer and understand the process of communication between a client and a server.

## Software Used
- Cisco Packet Tracer

## Description
This experiment involves setting up a client-server network to study communication using TCP and UDP protocols. Different services are configured on the server, and client devices access these services to understand data transmission, connection establishment, reliability, and communication mechanisms of both protocols.

## Result
Successfully studied and simulated client-server communication using TCP and UDP protocols in Cisco Packet Tracer.

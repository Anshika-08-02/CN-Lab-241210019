# Experiment 11: Client-Server Model Using TCP Protocol

## Aim
To study and implement the client-server model using Cisco Packet Tracer and understand socket-based communication between client computers and a server using TCP protocol.

## Software Used
- Cisco Packet Tracer

## Description
This experiment involves establishing a client-server network in Cisco Packet Tracer, where client computers communicate with a server using the TCP protocol. The server is configured to provide network services, and clients access these services through socket-based communication. The experiment demonstrates connection establishment, reliable data transmission, and connection termination using TCP.

## Result
Successfully implemented the client-server model and studied TCP-based communication between client computers and a server using Cisco Packet Tracer.

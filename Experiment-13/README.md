# Experiment 13: DHCP Server Implementation

## Aim
To study and implement a Dynamic Host Configuration Protocol (DHCP) server using Cisco Packet Tracer and understand the automatic assignment of IP addresses and other network configuration parameters to client devices.

## Software Used
- Cisco Packet Tracer

## Description
This experiment involves configuring a DHCP server to automatically assign IP addresses, subnet masks, default gateways, and DNS server addresses to client computers. The clients are configured to obtain IP addresses dynamically, and network connectivity is verified using the `ping` command.

## Result
Successfully implemented a DHCP server and verified the automatic assignment of IP addresses and network configuration parameters to client devices using Cisco Packet Tracer.

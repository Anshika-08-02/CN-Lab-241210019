# Experiment 6: Router Configuration Using Cisco Packet Tracer

## Aim
To study and perform router configuration using Cisco Packet Tracer by assigning IP addresses to router interfaces, connecting two different networks, and establishing communication between computers through a router.

## Software Used
- Cisco Packet Tracer

## Description
This experiment involves configuring router interfaces with appropriate IP addresses and subnet masks to connect two different networks. Computers are connected to the router through switches, and default gateways are configured to enable communication between the networks. Connectivity is verified using the `ping` command.

## Result
Successfully configured a router, connected two different networks, and established communication between computers through the router using Cisco Packet Tracer.

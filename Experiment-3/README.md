# Experiment 3: Study of Networking Devices

## Aim
To study and install various networking devices using Cisco Packet Tracer and understand their functions and applications in computer networks.

## Software Used
- Cisco Packet Tracer

## Description
This experiment involves studying various networking devices such as routers, switches, hubs, bridges, repeaters, and access points. These devices are added and configured in Cisco Packet Tracer to understand their roles in establishing and managing network communication.

## Result
Successfully studied various networking devices, their functions, and applications using Cisco Packet Tracer.

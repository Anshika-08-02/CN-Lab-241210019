# Experiment 8: Network Address Translation (NAT)

## Aim
To study and examine Network Address Translation (NAT) using Cisco Packet Tracer and configure a router to translate private IP addresses into a public IP address for communication with an external network.

## Software Used
- Cisco Packet Tracer

## Description
This experiment involves configuring Network Address Translation (NAT) on a router to allow devices in a private network to communicate with an external network. The router translates private IP addresses into public IP addresses using NAT configuration. Connectivity is verified using the `ping` command.

## Result
Successfully studied and configured Network Address Translation (NAT) using Cisco Packet Tracer and established communication between a private network and an external network.

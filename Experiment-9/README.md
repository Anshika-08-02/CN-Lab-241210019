# Experiment 9: Implementation of Routing Protocols

## Aim
To study, configure and simulate various routing protocols such as RIP, OSPF and EIGRP using Cisco Packet Tracer, and understand how routers exchange routing information and establish communication between different networks.

## Software Used
- Cisco Packet Tracer

## Description
This experiment involves configuring different dynamic routing protocols, including RIP, OSPF and EIGRP, on routers using Cisco Packet Tracer. The routing tables are examined to understand how routers exchange network information and determine the best path for data transmission. Connectivity between different networks is verified using the `ping` command.

## Result
Successfully configured and simulated RIP, OSPF and EIGRP routing protocols and established communication between different networks using Cisco Packet Tracer.
